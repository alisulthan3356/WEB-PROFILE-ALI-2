2D ACTION / PLATFORMER IN DEVELOPMENT

Shadow Realm

Game platformer aksi 2D bertema gelap dengan mekanik aksi cepat, eksplorasi dungeon, dan pertarungan boss yang menantang.

CORE MECHANICS
  • Movement: Dash, Wall-slide, & Double-jump presisi.
  • Combat: Fast-paced melee combo & parry timing.
  • Level Design: Dungeon non-linear dengan area rahasia.
TECH STACK
Godot Engine 4 GDScript Pixel Art (Aseprite)
PUZZLE / MINIMALIST PROTOTYPE

Grid Shift

Game teka-teki logika berbasis petak tempat pemain memanipulasi ruang dan gravitasi untuk menyelesaikan setiap level.

CORE MECHANICS
  • Spatial Logic: Pergeseran matriks petak (Grid Matrix Shift).
  • Gravity Flip: Rotasi gravitasi 90° & 180°.
  • Constraints: Jumlah langkah terbatas di setiap stage.
TECH STACK
HTML5 Canvas Vanilla JavaScript CSS Grid / Flexbox
